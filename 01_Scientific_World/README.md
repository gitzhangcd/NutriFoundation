# AI Nutri Scientific Evidence World

## Purpose

This module defines the scientific knowledge layer of AI Nutri Data Foundation v0.1.

The objective is not to build a traditional nutrition knowledge base, but to construct a traceable scientific evidence ecosystem:

```text
SourceArtifact
      ↓
EvidenceUnit
      ↓
ScientificClaim
      ↓
EvidenceSynthesis
      ↓
Decision Support
```

## Scientific Principle

AI Nutri separates:

```
Source ≠ Evidence ≠ Claim ≠ Recommendation
```

Every scientific object must preserve:

- provenance
- evidence boundary
- uncertainty
- applicability limitation
- version

## P1 Goal

Construct the first scientific evidence pilot:

```
100 SourceArtifact
        ↓
EvidenceUnit extraction
        ↓
ScientificClaim registry
```

This dataset will support DecisionEpisode Benchmark construction.
