# First SourceArtifact Bootstrap Plan v0.1

## Objective

Initialize the first verified SourceArtifact registry.

Target:

```text
100 SourceArtifact
```

## Sampling Strategy

| Type | Target |
|---|---:|
| Guidelines | 20 |
| Consensus / Position Statements | 10 |
| Meta-analysis | 25 |
| Systematic Reviews | 10 |
| RCT | 25 |
| Cohort | 10 |

## Priority Domains

- Obesity
- Diabetes
- Cardiovascular nutrition
- Aging and sarcopenia
- Kidney nutrition
- Micronutrients
- Cancer nutrition

## Bootstrap Rule

Each SourceArtifact requires:

1. Metadata verification
2. Provenance record
3. Evidence extraction eligibility assessment
4. Version registration

Only registered SourceArtifacts can generate EvidenceUnits.
