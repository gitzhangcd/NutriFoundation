# Scientific Claim Registry

## Purpose

Store validated scientific claims derived from evidence objects.

## Claim Lifecycle

```text
EvidenceUnit
      ↓
Candidate Claim
      ↓
Verification
      ↓
Frozen ScientificClaim
```

## Claim Requirements

Every claim must include:

- evidence references
- population boundary
- uncertainty
- limitations
- applicability boundary

Claims are not recommendations.
