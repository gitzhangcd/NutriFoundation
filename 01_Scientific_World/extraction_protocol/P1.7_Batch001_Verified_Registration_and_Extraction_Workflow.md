# AI Nutri Data Foundation v0.1

# P1.7 Batch001 Verified Registration and Extraction Workflow

## Objective

Transform screened literature candidates into verified SourceArtifact objects and generate EvidenceUnit candidates.

## Workflow

Literature candidate

→ Eligibility confirmation

→ SourceArtifact registration

→ Agent Evidence Extraction

→ EvidenceUnit candidate

→ Verification queue

→ Human audit

→ Frozen EvidenceUnit

## SourceArtifact freeze criteria

- authoritative identifier available
- source type confirmed
- nutrition domain classified
- provenance recorded

## EvidenceUnit extraction fields

- Population
- Intervention/Exposure
- Comparator
- Outcome
- Effect estimate
- Follow-up
- Certainty
- Source span

## Agent boundary

Agents may extract and structure information.

Agents may not:

- assign final scientific truth
- override evidence certainty
- generate individual recommendations

## Human review responsibility

Human experts confirm:

- scientific interpretation
- evidence limitation
- applicability boundary
