# AI Nutri Data Foundation v0.1

# P1.6 Batch001 Literature Retrieval Protocol

## Objective

Construct the first real SourceArtifact registry batch (SA-B001-001~020) following the frozen Data Contract.

## Pipeline

Literature Source

→ Eligibility Screening

→ SourceArtifact Registration

→ Evidence Extraction Queue

→ Verification

→ Frozen EvidenceUnit

## Inclusion Criteria

- Human nutrition research
- Clear population definition
- Explicit intervention/exposure
- Explicit comparator where applicable
- Measurable outcome
- Traceable bibliographic metadata

## Exclusion Criteria

- Opinion without evidence basis
- Non-human-only studies for individual decision benchmark
- Missing outcome definition
- Unverifiable source

## Required Metadata

- source_id
- title
- DOI/PMID
- evidence type
- nutrition domain
- retrieval date
- inclusion rationale
- provenance
