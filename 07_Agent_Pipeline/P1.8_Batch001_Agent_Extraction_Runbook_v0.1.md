## Extraction Scope

Agent extracts:

- Population
- Intervention/Exposure
- Comparator
- Outcome
- Effect estimate
- Follow-up
- Limitations
- Evidence certainty

## Agent Boundary

Agents may propose structured objects but cannot independently freeze scientific claims or expert references.

## Quality Gates

1. Provenance completeness
2. Source span availability
3. Schema compliance
4. Scientific interpretation review
