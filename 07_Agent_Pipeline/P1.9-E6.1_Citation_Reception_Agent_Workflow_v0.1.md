# P1.9-E6.1 Citation Reception Agent Workflow v0.1

## Objective

Operationalize claim-level scientific reception analysis in the chat-window Agent workflow.

## Pipeline

ScientificClaim_candidate → Target Source Resolution → Citation Graph Retrieval → Citation Context Extraction → Claim Alignment → Reception Role → Evidence-Lineage De-duplication → Independent Replication Detection → Integrity Check → CitationReceptionRecord + ScientificInfluenceSignal → ClaimReliabilitySignal → E7 Qualification Queue.

## Agent roles

### Retrieval Agent
- resolve PMID/DOI/canonical identifiers
- retrieve citing publications and available citation contexts
- retrieve publication type/year
- retrieve correction/erratum/retraction metadata
- retrieve citation counts and normalized indicators when available

### Citation Context Agent
- identify which target claim is being cited
- classify exact/partial/background/unclear alignment
- classify supports/contrasts/contradicts/replication/failed-replication/methodological-use/background/extension/critique
- preserve the minimal evidence span
- attach classification confidence

### Independence Agent
- detect same cohort reuse
- detect same trial follow-up
- detect derivative review/guideline lineage
- detect shared meta-analysis primary studies
- detect overlapping research groups and datasets

### Replication Agent
- direct_replication
- conceptual_replication
- null_replication
- failed_replication
- not_comparable

### Integrity Agent
Check correction, erratum, expression of concern, retraction and major published methodological critique.

### Reliability Synthesis Agent
Create the reliability vector. A one-number truth score is prohibited in v0.1.

## Human escalation

Mandatory for contradicts, failed_replication, major critique, result-changing correction, expression_of_concern, retraction, and ambiguous claim alignment that could change E7 Gold eligibility.

## Default chat-window execution unit

1 ScientificClaim → all core supporting SourceArtifacts → claim-aligned citation/reception graph → independent replication check → reliability sidecar.

For highly cited targets, use stratified retrieval first: recent citations, systematic reviews/meta-analyses, guidelines, explicit critique/contradiction, and independent replications. Background mentions need not all be manually classified before the first sidecar is created.

## Outputs

- CitationReceptionRecord(s)
- ScientificInfluenceSignal(s)
- ClaimReliabilitySignal
- ExecutionLog
- HumanEscalationQueue

## Scientific boundary

The Agent may classify and summarize scientific reception. It may not silently convert popularity into truth or freeze ScientificClaim_GOLD without independent human/expert adjudication.
