# P1.9 Batch001 Evidence Extraction Output Contract v0.1

## Agent Output

The extraction agent produces candidate EvidenceUnit objects only.

## Required Fields

- evidence_id
- source_id
- population
- intervention_or_exposure
- comparator
- outcome
- effect
- follow_up
- limitation
- source_span
- confidence

## Boundary

Agent outputs remain candidates until verification.

```text
Candidate EvidenceUnit
        |
        v
Verification Queue
        |
        v
Frozen EvidenceUnit
```

The agent cannot generate recommendations or alter evidence certainty.
