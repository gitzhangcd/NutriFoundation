# E0.1｜NutriFoundation Engine Executable Contract Freeze

## Status

`REFERENCE IMPLEMENTATION / EXECUTABLE CONTRACT FREEZE`

## Purpose

E0.1 converts the already frozen AI Nutri scientific semantics into executable software constraints without redefining the scientific ontology.

## Core invariants enforced in code

- `Observation != Evidence`
- `Citation != EvidenceUnit`
- `EvidenceUnit != ScientificClaim`
- `ScientificInfluence != ClaimReliability`
- `CitationCount != SupportCount`
- `SupportiveCitation != IndependentReplication`
- `JournalMetric != ArticleValidity`
- `AgentOnlyApproval != ScientificClaim_GOLD`

## Domain models

The reference implementation defines immutable Pydantic models for:

- `SourceArtifact`
- `EvidenceUnit`
- `ScientificClaim`
- `CitationReceptionRecord`
- `ScientificInfluenceSignal`
- `ClaimReliabilitySignal`
- `HumanAdjudicationRecord`
- `GoldScientificClaim`

These are implementation types; the scientific YAML schemas remain the normative semantic authority.

## Workflow state machine

```text
RETRIEVED
→ METADATA_VERIFIED
→ SOURCE_REGISTERED
→ EXTRACTED_CANDIDATE
→ VERIFIED_CANDIDATE
→ F0_FROZEN
→ F1_FULLTEXT_VERIFIED (when available/required)
→ CLAIM_CANDIDATE
→ RECEPTION_QUALIFIED
→ RELIABILITY_QUALIFIED
→ HUMAN_ADJUDICATION_PENDING
→ GOLD
```

No transition may skip directly from `CLAIM_CANDIDATE` or `RELIABILITY_QUALIFIED` to `GOLD`.

## GOLD guard

The transition to `GOLD` requires all of:

1. a `HumanAdjudicationRecord`;
2. reviewer identity and role;
3. reviewer independence from Agent extraction;
4. explicit `APPROVE_GOLD_AS_WRITTEN` or `APPROVE_GOLD_WITH_REVISION`;
5. explicit approved wording;
6. at least one F1/full-text qualification anchor;
7. reliability qualification sidecar.

Agent-only approval is invalid by construction.

## E0.1 non-goals

E0.1 does not yet implement:

- PubMed/PMC HTTP connector;
- PostgreSQL persistence;
- background job orchestration;
- LLM extraction prompts;
- human web workbench;
- automatic citation graph provider integration.

Those are downstream E0.2/E0.3 implementation stages. E0.1 freezes the executable scientific contract first.

## Regression fixture

The existing Batch001 Gold registry is used as a regression fixture. The reference tests require:

- `frozen_gold_count == 0`;
- three machine-qualified claims remain human-adjudication pending;
- no code path may silently promote them to GOLD.
