# E0.1 Execution Report

## Objective

Implement the first executable reference layer for NutriFoundation without changing frozen scientific semantics.

## Implemented

### Package and build

- `pyproject.toml`
- package `nutrifoundation-engine==0.1.0`
- Python >= 3.11
- dependencies: Pydantic, PyYAML, Typer

### Frozen domain models

Implemented immutable Pydantic models for:

- SourceArtifact
- EvidenceUnit
- ScientificClaim
- CitationReceptionRecord
- ScientificInfluenceSignal
- ClaimReliabilitySignal
- HumanAdjudicationRecord
- GoldScientificClaim

### Executable invariants

Code enforces:

- Citation != EvidenceUnit
- EvidenceUnit != ScientificClaim
- ScientificInfluence != ClaimReliability
- citation popularity cannot be the sole basis of reliability upgrade
- retracted evidence cannot remain robust/convergent
- causal claim requires evidence references
- human Gold approval must be independent from Agent extraction

### Workflow state machine

Implemented legal lifecycle:

```text
RETRIEVED
→ METADATA_VERIFIED
→ SOURCE_REGISTERED
→ EXTRACTED_CANDIDATE
→ VERIFIED_CANDIDATE
→ F0_FROZEN
→ F1_FULLTEXT_VERIFIED
→ CLAIM_CANDIDATE
→ RECEPTION_QUALIFIED
→ RELIABILITY_QUALIFIED
→ HUMAN_ADJUDICATION_PENDING
→ GOLD
```

Hard guards prohibit:

- CLAIM_CANDIDATE → GOLD
- GOLD without HumanAdjudicationRecord
- GOLD without independent human approval
- GOLD without explicit approved wording
- GOLD without F1/full-text anchor

### CLI

Implemented:

```bash
nutri contract-check
nutri validate-gold-gate <registry.yaml>
```

### Regression tests

Local execution before push:

```text
8 passed
```

Tests cover:

- influence-only reliability inflation rejection
- retraction guard
- independent human Gold requirement
- no state-machine skip to Gold
- F1 required for Gold
- valid human-approved Gold transition
- Batch001 remains 3 human-pending / 0 Gold

### CI

Added GitHub Actions workflow:

`.github/workflows/engine-ci.yml`

It installs the package, runs pytest, runs executable invariant checks, and validates the Batch001 Gold gate fixture.

## Non-goals / deferred

E0.1 intentionally does not yet implement:

- live PubMed/PMC connectors
- PostgreSQL persistence
- LLM extraction/verifier agents
- citation graph provider adapters
- job orchestration
- human adjudication web UI

These should be implemented after the executable scientific contract has been frozen.

## Exit decision

E0.1: PASS

Reason:

- scientific semantics preserved
- state transitions executable
- Gold governance enforced in code
- regression tests pass locally
- CI definition committed
- Batch001 used as regression fixture
