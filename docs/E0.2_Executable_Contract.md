# E0.2｜Persistence Layer, PubMed / PMC Connectors, RunManifest, SourceArtifact Ingestion & Batch001 Replay

## Status

`REFERENCE IMPLEMENTATION / EXECUTABLE CONTRACT FREEZE`

## Scientific boundary

E0.2 does not change any E0.1 scientific object semantics.

It adds an execution and persistence layer beneath the frozen contracts:

```text
RunManifest
    +
PubMed / PMC retrieval
    ↓
SourceArtifact ingestion
    ↓
SQLite persistence
    ↓
Replay / audit
```

## Persistence contract

Reference persistence is SQLite in v0.2.

Tables:

- `run_manifest`
- `source_artifact`
- `source_full_text`
- `ingestion_event`

The persistence interface is intentionally small so a later PostgreSQL implementation can preserve the same domain/service contracts.

### SourceArtifact persistence

Every persisted SourceArtifact retains:

- source_id
- PMID / PMCID / DOI
- title
- source type
- publication date
- immutable serialized domain payload
- SHA-256 of serialized payload
- provenance
- RunManifest identifier in provenance metadata

### Full-text persistence

PMC full text is stored as exact retrieved XML plus SHA-256 and retrieval timestamp.

No OCR or LLM rewriting occurs at this layer.

## RunManifest contract

Every ingestion/replay run MUST create a RunManifest before retrieval begins.

A RunManifest records:

- run_id
- pipeline name/version
- live/offline/test mode
- start/end timestamps
- providers
- code version
- inputs
- outputs
- errors
- final status

A completed RunManifest is immutable. Attempting to silently rewrite it raises an error.

## PubMed connector

The live PubMed connector uses NCBI E-utilities `efetch` and parses:

- PMID
- title
- journal
- publication date
- authors
- DOI
- PMCID
- publication types
- abstract text

NCBI provider provenance is preserved.

Production usage SHOULD set `NUTRIFOUNDATION_EMAIL`; `NCBI_API_KEY` is optional.

## PMC connector

The live PMC connector uses NCBI E-utilities `efetch` with `db=pmc` and stores exact XML.

Availability of full text remains a rights/access property. Failure to retrieve PMC text MUST NOT be converted into F1 verification.

## Source type classification

PubMed publication types are mapped conservatively:

- randomized/clinical trial → RCT
- observational/cohort → Cohort
- meta-analysis/network meta-analysis → MetaAnalysis
- systematic review → SystematicReview
- practice guideline → Guideline
- title-level consensus report → Consensus

Corrected/re-published records preserve underlying RCT type only when retrieved text preserves randomized assignment semantics.

Raw publication types remain in provenance.

## Batch001 replay contract

Batch001 replay takes:

```text
Verified SourceArtifact Registry
        +
PubMed provider
        ↓
SourceArtifact ingestion
        ↓
fresh database
        ↓
identity comparison
```

v0.2 replay qualification requires:

- expected source count preserved
- source_id preserved
- PMID exact match
- DOI normalized exact match
- zero missing SourceArtifacts
- completed RunManifest

The deterministic CI replay fixture is an identity/provenance fixture only. It is not a scientific evidence source and does not replace live PubMed.

## Live vs offline modes

### offline_replay

Used for CI/regression.

- no public network required
- deterministic fixture
- validates ingestion, persistence, lineage and identity preservation

### live

Used for production retrieval.

- PubMed/PMC accessed through NCBI E-utilities
- current metadata retrieved
- provider and retrieval time preserved in provenance

## Non-regression invariants

E0.2 MUST preserve all E0.1 invariants, including:

- Citation != EvidenceUnit
- Influence != Reliability
- Agent-only approval != ScientificClaim_GOLD

Additional E0.2 invariants:

- every ingestion run has RunManifest
- completed RunManifest is immutable
- SourceArtifact export retains run_id provenance
- offline replay fixture is not scientific authority
- replay must preserve source identity
- failed full-text retrieval cannot be represented as F1 verification

## Exit criteria

E0.2 passes when:

1. persistence layer is executable;
2. PubMed XML parser is tested;
3. PMC connector request contract is tested;
4. SourceArtifact ingestion creates RunManifest + provenance;
5. completed RunManifest immutability is tested;
6. Batch001 deterministic replay stores 20 sources;
7. all 20 PMIDs and 20 DOIs match the authoritative registry;
8. previous Gold-gate regression tests remain green;
9. CI runs the deterministic Batch001 replay.
