# E0.4.1 Fresh-Context Strict-Blind Handoff

Use this protocol only in a genuinely fresh model/chat context.

## Allowed inputs

The fresh worker may receive:

- source-only TaskBundle files generated from `fixtures/Batch001_Blind_SourceText_v0.1.json`;
- E0.4.1 semantic extraction rules;
- ResponseEnvelope schema.

## Forbidden inputs

Do not provide:

- `Batch001_EvidenceUnit_Frozen_v0.1.yaml`;
- E0.4 response files;
- E0.4/E0.4.1 scoring reports;
- prior Batch001 answers or wording;
- model-assisted calibration labels.

## Required response metadata

Every ResponseEnvelope must record:

```json
{
  "fresh_context_attestation": true,
  "prior_batch_exposure": false,
  "hidden_reference_available_to_worker": false,
  "independent_worker_session": true,
  "strict_blind_protocol_version": "E0.4.1-v0.1"
}
```

## Validation

```bash
nutri validate-strict-blind runs/E0.4.1/StrictBlind/responses --require
```

If this fails, do not score the run.

## Scoring

Only after validation passes:

```bash
nutri score-strict-blind-batch runs/E0.4.1/StrictBlind/responses
```

The scorer then runs:

```text
strict-blind attestation
→ operational verifier/F0 replay
→ hidden-reference canonical semantic scoring
```

The attestation documents protocol state; it is not cryptographic proof of absence of prior exposure.
