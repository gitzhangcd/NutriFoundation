## Purpose

The design keeps the E0.4 task contract fixed and changes only the worker-context blindness condition.

```text
same source-only task

+ same response schema
+ fresh independent context
= strict-blind comparability
```

## Blind wall

The fresh-context handoff may contain only source-side extraction material.

It MUST NOT contain:

- frozen EvidenceUnit reference data;
- previous semantic responses;
- previous scoring reports;
- canonical equivalence reports;
- development calibration labels;
- ScientificClaim Gold.

The executable audit checks:

- task count and identity uniqueness;
- task SHA equality;
- source-text SHA equality;
- forbidden artifact tokens;
- forbidden payload keys;
- reference-answer visibility;
- prior response inclusion;
- hidden reference inclusion;
- scoring artifact inclusion.

## Required fresh-context attestation

Every strict-blind response requires:

```text
fresh_context_attestation = true
prior_batch_exposure = false
hidden_reference_available_to_worker = false
independent_worker_session = true
blindness_class = strict_blind_fresh_context
```

The attestation is protocol evidence, not cryptographic proof.
