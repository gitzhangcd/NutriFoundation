# E0.4.2-E1｜Error Attribution Matrix & Evaluation Failure Taxonomy Freeze

## Purpose

E0.4.2-E1 separates true semantic extraction errors from benchmark, ontology, provenance and measurement artifacts after strict-blind scoring.

The frozen worker responses are immutable. This stage only analyzes the evaluation pathway.

## Core principle

```text
Observed mismatch
        ↓
Attribution before correction
        ↓
Model error / Evaluator error / Information asymmetry / Contract defect
```

## Attribution dimensions

| Category | Definition | Example |
|---|---|---|
| True Semantic Error | Worker reconstructed scientific meaning incorrectly | Wrong effect direction |
| Ontology Alignment Error | Representation mismatch | StudyType vs EvidenceKind |
| Provenance Contract Error | Anchor requirement unavailable to worker | PMID not in source text |
| Numeric Normalization Error | Equivalent values scored as different | .20 vs 0.20 |
| Information-Set Asymmetry | Reference had information unavailable to worker | Abstract unavailable vs PMC full text |
| Safe Abstention | Correct defer under insufficient evidence | TASK-BLIND-B001-015 |

## Frozen questions

1. Did the worker have sufficient information?
2. Was the scientific meaning preserved?
3. Was the mismatch caused by representation?
4. Was the evaluator contract fair?

## Invariant

```text
FrozenResponseSet must not be modified during attribution.
Attribution precedes evaluator repair.
Evaluator repair must not change original experimental outcome.
```

## Output

E0.4.2-E1 produces an attribution matrix, not a revised worker response set.
