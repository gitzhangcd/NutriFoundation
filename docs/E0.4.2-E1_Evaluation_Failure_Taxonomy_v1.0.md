# E0.4.2-E1｜Evaluation Failure Taxonomy

## Taxonomy

```text
Evaluation discrepancy
|
+-- A. Worker Semantic Failure
|      +-- factual extraction error
|      +-- effect interpretation error
|      +-- applicability boundary loss
|
+-- B. Scientific Representation Failure
|      +-- study design / evidence kind conflation
|      +-- claim ontology mismatch
|
+-- C. Measurement Contract Failure
|      +-- literal numeric matching
|      +-- surface-form mismatch
|      +-- insufficient semantic normalization
|
+-- D. Provenance Contract Failure
|      +-- unavailable anchor
|      +-- source/reference information asymmetry
|
+-- E. Correct Scientific Abstention
       +-- insufficient evidence
       +-- hallucination avoidance
```

## Interpretation rule

A lower canonical score does not automatically imply lower scientific capability.

The attribution layer must determine whether the mismatch belongs to the worker, the representation, or the evaluator.
