# E0.4.2-E2｜Canonical Scoring Schema v1.0

## Purpose

The scoring system is redesigned to avoid treating evaluator artifacts as intelligence failures.

## Score Dimensions

## S1 Scientific Core Semantic Equivalence

Target fields:

```text
Population
Exposure/Intervention
Comparator
Outcome
Effect
Applicability Boundary
```

This is the primary scientific metric.

---

## S2 Study Ontology Alignment

Measures:

```text
Study Design
Claim Type
Evidence Role
```

Example:

```text
Cohort
+
observational_association
```

is preferred over a single ambiguous kind field.

---

## S3 Provenance Recoverability

Separate:

```text
Available source anchors

vs

External identifiers unavailable to worker
```

---

## S4 Numerical Semantic Fidelity

Numbers are compared after normalization:

```text
0.20 == .20
100000 == 100,000
```

while preserving original surface form separately.

---

## S5 Safe Abstention

A defer response is positive evidence when:

```text
source insufficiency
        ->
no unsupported inference
```

---

## Reporting Format

Future reports should provide:

```text
Scientific Semantic Recovery: XX%
Ontology Alignment: XX%
Provenance Recovery: XX%
Numeric Fidelity: XX%
Safe Abstention Quality: XX%
```

and should not collapse all dimensions into one number.

---

## Re-scoring Rule

The frozen E0.4.2-C response set is reused unchanged.

Only the evaluator version changes.

This preserves experimental validity.
