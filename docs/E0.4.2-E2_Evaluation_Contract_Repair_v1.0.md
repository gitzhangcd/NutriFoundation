# E0.4.2-E2｜Scientific Evidence Evaluation Contract Repair, Ontology Separation & Canonical Scoring Redesign Freeze

## Status

`DESIGN FREEZE`

## Objective

E0.4.2-E2 does not modify frozen Worker ResponseEnvelopes.

The objective is to repair the evaluation contract so that scientific semantic performance is separated from representation, provenance, and measurement artifacts.

Core principle:

```text
Model semantic capability != evaluator surface-form agreement
```

---

# 1. Evaluation Layer Separation

Previous mixed evaluation:

```text
Canonical Equivalence
    = Semantic
    + Ontology
    + Provenance
    + Surface Normalization
```

New contract:

```text
Scientific Semantic Layer
        |
        +-- Ontology Layer
        |
        +-- Provenance Layer
        |
        +-- Measurement Layer
```

---

# 2. Ontology Separation Contract

## Previous

```yaml
kind:
    Cohort
```

Problem:

Study design and evidence meaning were conflated.

## New

```yaml
study_design:
    cohort

claim_type:
    observational_association

intervention_mode:
    exposure_observation
```

Required separation:

```text
Study Design
!=
Scientific Claim Type
```

---

# 3. Evidence Anchor Redesign

Previous:

```yaml
anchor
```

New:

```yaml
semantic_anchor:
    source_text_span

provenance_anchor:
    PMID/DOI/PMCID

retrieval_identifier:
    external_locator
```

Rule:

```text
Unobservable provenance cannot be scored as source-only semantic failure.
```

---

# 4. Numeric Semantic Normalization

Surface forms:

```text
.20
0.20
0.200
```

are normalized to:

```text
0.2
```

Equivalent representations:

```text
100 000
100,000
100000
```

must not create semantic mismatch.
