## Mechanism-level attribution

### Provenance representation artifact: 20 events

All 20 V1 `anchor:mismatch` events are reclassified as evaluator artifacts.

V1 expected a reference-style anchor such as a PubMed identifier. The strict-blind worker instead returned a semantic anchor plus `source_span`. Evaluator V2 verifies whether that span is supported by the worker-visible source text.

A2.6 shows:

```text
source_span_supported = 20 / 20
Provenance Recovery   = 1.0
```

Therefore the V1 anchor failures were representation failures of the evaluator, not unsupported provenance by the worker.

### Safe-abstention artifact: 1 event

For `EU-B001-015`, the source contained a title and explicitly stated that the PubMed abstract was unavailable.

The worker returned `defer`. V1 nevertheless counted the absent recommendation as a missing critical field. V2 evaluates abstention explicitly:

```text
source insufficient + defer
→ correct_safe_abstention
→ score = 1.0
```

The V1 `recommendation:missing` event is therefore frozen as an evaluator artifact.

### Preserved semantic residuals: 6 events

Six V1 field discrepancies remain semantic deficits in V2:

- comparator: 3
- outcome: 1
- population: 1
- recommendation/effect semantics: 1

These should remain in the scientific error budget under the current F0 reference.

### Numeric residual reclassification: 2 events

Two V1 `effect:partial` events are no longer interpreted as semantic failures. V2 recovers their semantics but retains the quantitative mismatch under Numeric Fidelity.

This is a dimensional reclassification:

[
	ext{V1 mixed semantic + numeric error}
ightarrow
	ext{V2 semantic recovery + numeric residual}
]

The residual is real under the current reference; only its **error locus** changes.

### Ontology / contract ambiguity: 6 events

Six V1 `kind:mismatch` events remain disagreements after V2 localization to `claim_type`.

However, V2 simultaneously shows that `study_design` and `evidence_role` are correctly recovered. The strict-blind worker contract required preservation of study type and causal level but did not define a closed vocabulary for legacy `kind`.

Therefore A2.7 freezes these as **ontology / contract ambiguity**, not as pure model errors and not as confirmed evaluator artifacts.

### Applicability-boundary unresolved: 9 events

Nine V1 canonical applicability-boundary discrepancies remain deliberately unresolved.

Evaluator V2 does not include semantic applicability-boundary recovery as one of the five Scientific Core fields. Some numeric boundary content can be evaluated independently, but that does not create an isomorphic semantic metric.

Therefore:

[

	ext{No V2 semantic boundary metric}
Rightarrow
	ext{No causal attribution}
}
]

## Why V1 67.88% and V2 94.74% must not be subtracted

[

These are not the same estimand.

V1 mixes a different set of fields and representations, including anchor and applicability-boundary behavior. V2 separates scientific semantics from ontology, numbers, provenance, and abstention.

Therefore this statement is **forbidden**:

> “Evaluator V2 improved accuracy by 26.86 percentage points.”

The valid interpretation is:

> V2 changes the evaluation decomposition and error attribution. Under that decomposition, scientific semantic recovery is high while numeric fidelity and claim-type alignment remain materially lower, and several V1 discrepancies are attributable to evaluator design.
