## Search strategy

The mining run used prospectively separated PubMed searches for primary interventional, primary observational, evidence synthesis, guideline/consensus, companion/secondary, held-out external-domain, and correction/retraction/living-version candidates.

Duplicates were removed by PMID before candidate IDs were assigned.

## Candidate identity

Candidate IDs are assigned as:

```text
G100-CAND-000001 ...
```

The raw registry preserves PMID, DOI/PMCID when returned, title, journal, publication date, authors, discovery queries, and PubMed provenance.

## No inflation rule

A candidate is counted only when a real PMID was returned. Search ideas, unverified titles, model-generated citations, and placeholder rows contribute zero to the candidate count.
