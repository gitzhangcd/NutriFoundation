## 3. Exact-text freeze

The pipeline does not treat PubMed abstracts as full text.

For PMCID-bound candidates, the qualification workflow attempts to retrieve structured fullTextXML and constructs a deterministic worker-visible representation:

```text
article title
+ abstract
+ body
→ whitespace normalization
→ SHA-256
```

References/back matter are excluded from the worker-visible text definition.

The workflow stores hashes, lengths, provenance and license metadata rather than committing copyrighted full text.

Across the final raw source universe:

```text
PMCID-bound fullTextXML retrieved/hashed = 389
natural incomplete-source stress cases  = 8
```

The 8 abstract-only cases are not substitutes for unavailable full text in Core sampling; they exist only under the prespecified incomplete/missing-source stress exception.

Authority:

```text

```

## 6. Coverage-repair lineage

Coverage repair was triggered only by frozen pre-sampling deficits and never by AB0–AB6 output.

### Initial qualification

```text
raw candidates = 342
eligible       = 104
status         = FROZEN_COVERAGE_GAP_NO_SAMPLING
```

Major deficits included observational, guideline, companion/StudyIdentity, external-domain and several challenge/stress categories.

### Repair v0.1

118 additional real PMID+PMCID candidates were mined from deficit-targeted searches.

This substantially repaired guideline and recommendation-exception coverage.

### Repair v0.2

204 additional real PMID+PMCID candidates targeted residual observational, companion/StudyIdentity, conflict, temporal and external-domain deficits.

A qualification implementation defect was then identified:

```text
ELIG-11 accepted only:
REAL_SOURCE_IDENTITY_BOUND
```

while legitimate repair records used versioned lineage values:

```text
REAL_SOURCE_IDENTITY_BOUND_COVERAGE_REPAIR*
```

This caused valid repair candidates to be falsely rejected as provenance failures.

The implementation was corrected to accept the frozen provenance prefix family. No scientific eligibility gate or threshold was changed.

After correction:

```text
eligible = 294
remaining gap = StudyIdentity_dependency only
```

### Repair v0.3

A final minimal repair added 60 real PMID+PMCID candidates specifically requiring secondary/post-hoc/subgroup trial evidence and trial-registration signals.

```text

all coverage gaps = 0
```
