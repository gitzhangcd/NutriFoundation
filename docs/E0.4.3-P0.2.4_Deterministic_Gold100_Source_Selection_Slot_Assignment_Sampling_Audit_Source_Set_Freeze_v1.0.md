## 2. Pre-sampling joint-feasibility audit

Before source assignment, an exact-slot feasibility audit exposed two issues that marginal P0.2.3 coverage counts could not detect.

### 2.1 StudyIdentity/external-companion joint constraint

The original pool had only one external companion/secondary StudyIdentity-dependent candidate, while the exact manifest simultaneously required one external Core companion slot, one external StudyIdentity stress slot, no SourceArtifact reuse, and a StudyIdentity challenge minimum >=15.

Therefore the 330-source parent pool was marginally sufficient but jointly infeasible.

### 2.2 Incomplete-source normative contradiction

The frozen design simultaneously required:

```text
Stress20 incomplete/missing-source-text slots = 2
orthogonal incomplete_source_text minimum >=5
```

while P0.2.1 ELIG-02 permits failure of exact-full-text sufficiency only inside the dedicated incomplete/missing-source-text stress stratum.

Thus >=5 incomplete sources could not legally coexist with only two legal incomplete-source slots. This was a protocol-level contradiction, not a data shortage.
