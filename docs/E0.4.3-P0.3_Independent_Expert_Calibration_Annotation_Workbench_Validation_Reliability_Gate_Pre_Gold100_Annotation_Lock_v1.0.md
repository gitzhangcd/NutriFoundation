## 1. Scientific purpose

P0.3 separates two claims that must never be conflated:

\[
\boxed{
\text{Machine-valid annotation system}
\neq
\text{Reliable independent expert annotation}
}
\]

The first can be tested automatically. The second requires real independent human annotations.

Therefore P0.3 freezes the calibration system now, but leaves the scientific pass/fail state open until human data exist.

## 4. Two-round calibration design

### Round A｜Calibration12A

Purpose: training, ambiguity discovery, and codebook/workbench debugging.

Procedure:

```text
Independent A first pass
+ Independent B first pass
→ both records hash-locked
→ differences released
→ facilitated discussion
→ classify disagreements
→ versioned manual/workbench repair if needed
```

Round A agreement metrics are diagnostic only. They are not the P0.3 pass gate.

### Round B｜Calibration12B

Purpose: blinded reliability validation under the exact manual/workbench version intended for Gold100.

Procedure:

```text
Frozen manual/workbench
→ independent A/B annotation
→ first-pass hash locks
→ pair lock
→ reliability calculation
→ metric freeze
→ only then discussion/adjudication may open
```

Round B is the actual reliability gate.
