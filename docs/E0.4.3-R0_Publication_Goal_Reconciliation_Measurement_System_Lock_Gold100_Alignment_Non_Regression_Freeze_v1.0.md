## 5. Measurement-system lock

Authoritative prospective contract:

```text

```

This contract closes the two A2.8 measurement gaps without retroactively changing A2.8.

### 5.1 Closed claim-type ontology

The allowed claim types are frozen to the existing ScientificClaim vocabulary:


No sixth claim type may be invented during confirmatory execution.

```text

```

No forced mapping is allowed.

### 5.2 Isomorphic applicability-boundary representation

For Paper C, applicability is frozen at **source-level evidence scope**, not individual-patient applicability.

Nine dimensions are prospectively represented:

```text
population_scope
intervention_or_exposure_scope
comparator_scope
outcome_scope
setting_context
temporal_scope
normative_exceptions
exclusions_or_contraindications
evidence_limitations
```

Each dimension receives one of:

```text
match
partial
mismatch
not_applicable
insufficient_source
```

`insufficient_source` is not forced into a model/evaluator error.  
`not_applicable` is excluded from the denominator.

Material scope corruption is critical when it changes a scientifically consequential population, exposure/intervention, outcome, temporal boundary, recommendation exception, or contraindication.

The nine historical A2.8 non-isomorphic events remain unchanged.

## 6. Primary measurement lock

The primary endpoint remains:

\[
CSER=
\frac{
\text{Critical Scientific Error Events}
}{
\text{Applicable Critical Error Opportunities}
}
\]

The source remains the clustering unit.

The eight opportunity types remain:

1. effect direction;
2. critical numeric result;
3. StudyIdentity/dependency;
4. causal level;
5. recommendation normativity/exception;
6. provenance/source span;
7. version/retraction/temporal status;
8. critical P/I/C/O scope.

High average field accuracy cannot cancel a critical error.

---

## 7. Numeric, provenance, identity and temporal lock

### Numeric fidelity

Source-reported values are exact after canonicalization. Formatting equivalence is allowed, but semantic unit conversion must be explicit. Rounding equivalence is limited to one-half unit of the last source-reported decimal place after unit normalization.

### Provenance/source span

A valid source span must:

1. exist in the exact worker-visible source text;
2. support the scientific object being asserted;
3. not omit a material qualifier that changes the meaning.

### StudyIdentity

Companion/dependency relationships must be resolved where applicable. Ambiguous identity escalates. Material double counting caused by wrong identity is a critical error.

### Temporal/version state

The evidence cutoff is fixed per case. Correction/retraction/living-version state must be resolved where applicable. Future-information leakage and invalid-version use are critical errors.
