## Numeric normalization audit

E0.4 exposed two verifier implementation defects.

### Percent representation

Source:

```text
11 percent
```

Response:

```text
11%
```

These are now normalized as equivalent.

### Range separator versus negative sign

Source:

```text
95% CI 7.8-49.8
```

The initial tokenizer incorrectly interpreted the range endpoint as `-49.8`.

Numeric tokenization now distinguishes:

```text
-5.3     = true negative value
7.8-49.8 = positive range endpoints
```

The same numeric rules are used by the verifier and benchmark scorer.

## Hidden-reference scoring

The frozen Batch001 F0 registry is loaded only after responses exist.

Reference comparison evaluates:

- evidence kind;
- population;
- intervention/exposure;
- comparator;
- outcome;
- effect;
- recommendation;
- applicability boundary;
- source anchor.

Field matching is deterministic lexical/structural triage:

- exact;
- near;
- partial;
- mismatch;
- missing;
- not applicable.

These labels are **not** expert semantic adjudication.

## Numeric hidden-reference comparison

The benchmark requires hidden-reference numeric tokens to be represented by the response when relevant.

Additional numeric detail is not an error when it is independently source-supported.

Thus:

```text
HiddenReferenceNumbers ⊆ ResponseNumbers
```

is acceptable.

## Two escalation concepts

E0.4 strictly separates production escalation from benchmark adjudication.

### Operational escalation

Can be computed without hidden reference.

Triggered by:

- defer/failed/missing response;
- verifier rejection;
- no F0 freeze;
- explicit semantic uncertainty.

This is the quantity relevant to production human workload.

### Benchmark adjudication flag

Requires hidden reference and is evaluation-only.

May be triggered by:

- operational escalation;
- high-risk hidden-reference field mismatch;
- hidden-reference numeric mismatch;
- causality-level mismatch.

Normative invariant:

```text
BenchmarkAdjudication != OperationalEscalation
```

A high benchmark adjudication rate must not be reported as production human workload.
