## Initial verifier result

```text
F0 yield       = 60%
```

Inspection showed that several rejections were caused by verifier tokenization rather than unsupported model content.

## Verifier repair 1 — percent normalization

The verifier initially treated:

```text
11 percent
```

and

```text
11%
```

as different numeric values.

After normalizing percent-word/symbol representation, the same unchanged response set produced:

```text
verifier yield = 75%
F0 yield       = 75%
```

## Verifier repair 2 — range separator

Raw rejection diagnostics showed four remaining rejected completed cases:

- EU-B001-010: source range endpoint `49.8` parsed as `-49.8`;
- EU-B001-013: `25-29` parsed with `-29`;
- EU-B001-014: `1.06-1.25` parsed with `-1.25`;
- EU-B001-020: confidence-interval endpoints parsed as negative values.

This was a deterministic numeric tokenizer defect.

The tokenizer was changed so a hyphen between numeric values is a range separator, while a true leading negative sign remains a negative value.

The semantic responses were not changed.

Final result:

```text
verifier yield = 95%
F0 yield       = 95%
```

The only non-F0 case remained the intentional EU-B001-015 defer.

## What the verifier audit demonstrates

The same fixed model responses moved:

```text
60% -> 75% -> 95%
```

solely because of verifier implementation corrections.

Therefore E0.4 empirically demonstrates:

```text
Observed Agent Pipeline Performance
=
Model Semantic Output
+
Verification System Quality
```

A weak verifier can substantially understate model/system capability.

## Hidden-reference benchmark adjudication

After operational processing finishes, the scorer loads the frozen Batch001 EvidenceUnit registry.

It flags:


for benchmark adjudication.

This 70% does **not** mean 70% of outputs are scientifically wrong and does **not** mean production requires 70% human review.

Many flags arise from:

- different but source-supported applicability wording;
- intervention/exposure granularity;
- scope phrasing;
- hidden-reference numeric selection;
- lexical normalization differences.

The deterministic field diagnostics are intentionally conservative.

## Scientific interpretation

E0.4 supports three engineering conclusions.

First, with source-only PubMed abstract input, the deterministic verifier accepted and froze 19/20 chat-model outputs; the only abstention was caused by missing source text.

Second, verifier implementation quality materially changes observed pipeline yield.

Third, exact hidden-reference wording is a poor proxy for scientific semantic equivalence: benchmark adjudication remains high despite high operational verifier yield.

These findings justify a separate semantic-canonicalization/calibration stage before using lexical hidden-reference agreement as a scientific model-accuracy measure.

## Limitations

1. Current conversation context had prior exposure to Batch001.
2. Therefore this run is not strict cognitive blind.
3. Most cases used PubMed abstract rather than uniformly available full text.
4. Lexical/structural hidden-reference scoring is not expert semantic adjudication.
5. A 20-case pilot is not a population-level estimate of general extraction performance.
