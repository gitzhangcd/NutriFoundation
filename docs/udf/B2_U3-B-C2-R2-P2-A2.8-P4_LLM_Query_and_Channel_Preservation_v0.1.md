# A2.8-P4 | Evidence-grounded LLM query reconstruction and semantic channel preservation
Authority: UDF v2.1 §§15–17, A2.7, A2.8-P3. Development only: existing 19+32 exposed cases, separately reported. No scientific mapping release or expert Gold.
## Three mechanism questions
H1: generative query hypotheses vs deterministic P3 reconstruction (same new matched candidate-generation run). H2: add original channels rather than replacing them. H3: independent identity/state/composition/region segments vs concatenated LLM views. Native target main-label representation R0 fixed for all arms. E5 checkpoint and 64-token limit unchanged. No new labels or target IDs are supplied to the query LLM.
## Generative contract
Use Qwen3-4B-Instruct-2507 MLX 4-bit public pinned revision 50d427756c6b1b2fe0c0a10f67fbda1fc8e82c1b, only if actual local runtime verifies. Frozen greedy decoding, max 384 new tokens, no retrieval augmentation or external dispatch. Source-only prompt: role and native label N, original aliases A1.., first five original recipe ingredient names I1.., no source ID or target/reference/rank fields. Four arrays of English search hypotheses with exact input evidence IDs: identity (whole entity), state/preparation, composition (reference recipe, not physical meal), region. Unknown may remain empty. Syntax, exact fields, anchor existence/roles and caps validated; evidence pointers do not establish entailment, correct translation, or scientific truth. Invalid output or empty identity means generative channel abstains; no retry/automatic answer substitution. Preserve raw completion and failure locally. All generated terms are hypotheses; no scientific claims.
## Six arms and paired controls
C0: original O0/O1. D0: previous deterministic D0/D1. L00: LLM concatenated M0/M1; L01: independent identity I, state S, composition C, region R, each anchored to whole identity; L10: original + concatenated; L11: original + segmented. Main contrast H1 L00-D0, H2 L10-L00 and L11-L01, H3 L01-L00 and L11-L10, interaction (L11-L10)-(L01-L00). Comparisons conditional on frozen development sample and search budget; no causal or statistical superiority beyond mechanisms as implemented.
For original scopes, fixed total proposal slots 40 (extension 24); equally divide within a single family, original+generated split 50:50 then equally within family. No reallocation for absent slots. Weighted RRF k=60, weights equally distributed within family, tie-break immutable target key. Preserve exact per-case/scope historical final cap (upper bound, not necessarily equal realized candidates). Same scoring/rank implementation across new arms; no promise of exact old H0/G0 replay, explicitly reconcile and report bridge. Original queries remain independently available in preservation arms; not a guarantee every original candidate survives fusion. C0/D0 are freshly matched arms; H0/P3 comparison descriptive.
Segmented views are packed deterministically at 64 E5 tokens, identity retained as prefix, omitted terms counted; monolithic baseline retains frozen truncation. Missing segments are not replaced. This compares complete segmentation/packing policy, not pure length intervention. Total encoding work can differ despite equal proposal slots; report actual query views, unspent slots, time and costs. LLM-only arms have no proposals when LLM identity abstains, original-preserving arms retain original slots; report generation failures and intention-to-treat results.
## Order of execution
P4.0 protocol and synthetic checks; P4.1 actual offline runtime qualification and small synthetic smoke; P4.2 generate and freeze all 51 source-only hypotheses in batches, no target/ref access; P4.3 local six-arm candidate generation and freeze; P4.4 separate post-freeze development evaluation and paired mechanism analysis. No reuse of 51 as unseen confirmation. No external model dispatch with private inputs; no method parameter changes after candidate freeze. No case-specific reference-directed query patching. Scientific reference qualification and source-family-disjoint confirmation remain separate.
