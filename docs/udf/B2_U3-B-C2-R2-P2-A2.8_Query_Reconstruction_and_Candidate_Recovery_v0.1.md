# A2.8 | Source-Grounded Query Reconstruction & Candidate Generation Recovery
Status: local development experiment, not scientific mapping release. Authority: UDF v2.1 §§15–17; A2.7 route decision. The previously exposed 19 and now exposed 32 cases are two separate development cohorts. No new unseen confirmation set is used.

## Controlled mechanism pilot (v0.1)
Four local matched arms with identical E5 checkpoint, target universe, native versions, per-case/scope frozen candidate caps, two query views, RRF k=60, and rank tie rule.
- G0: original recorded label/context queries × main-label target representation (fresh matched baseline, not claimed identical to historical quantized execution).
- G1: source-grounded two-view query reconstruction × main-label targets.
- G2: original query × native multi-surface targets (max cosine across main label and a second native alias/definition passage).
- G3: reconstructed query × native multi-surface targets.
- H0: historical BASELINE_FUSION from frozen ranks, read only in separate post-freeze evaluation; descriptive baseline bridge.
Q1 keeps the whole native label first, uses native entity role, source-native aliases, source-recorded state mentions, first five reference recipe ingredients, and frozen lexicon span-anchored English hypotheses. No target IDs, target label feedback, reference outputs or new invented identity. Source spans are not expert-verified translations. No local generative LLM available in preflight; this deterministic variant is a bounded pilot and does not test LLM reasoning. No external model dispatch, training, download, or private source export.
R1 preserves the native target ID; adds at most one passage per target consisting of main label, first three unique deterministically ordered native aliases and first definition if present. No graph expansion, no altered scope, no formal relation inference. Target surface strings may truncate at the unchanged 64-token encoder limit; report actual truncation. Same RRF candidate input top20 per form for original scopes, top12 per form for extension; preserve original per-case cap. Factorial comparisons are G1-G0, G2-G0, G3-G2, G3-G1 and interaction, separate cohorts/domains. No post hoc parameter selection.
Generate ranks source-only, hash and close output before separate evaluation; only then load already exposed references. Main outcome original scope Reference-Hit@12, secondary edge overlap, full-pool, negative overlap and nonrelated/conservative sensitivity if compatible reference definitions; no unreviewed-edge error claim. H0 remains historical comparator, not silently overwritten. No confirmed superiority or external generalization from these cohorts. New source-family-disjoint confirmation and independent expert reference require separate future plan. Candidate rank does not authorize mapping, nutrient transfer, or publication.
