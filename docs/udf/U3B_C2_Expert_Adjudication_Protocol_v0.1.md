# U3-B-C2｜专家审核执行说明 v0.1

用途：开发性专业裁定，不是确认性科学Gold。

## 阶段 A：独立原始判断
仅查看 ExpertSourceFirstQueue 对应的任务、允许的真实源资料和固定标准原件。记录对象粒度、明确状态、加工、物种/品种、可食部、组成、地区以及每项证据。未知保留 null + UNRESOLVED。先独立检索合适目标；可以保留条件性候选、无法判定或无可支持目标。不可使用生成器/模型分数作为科学依据。填写 ExpertAdjudicationResponse_v0.1.schema.json 的 INITIAL_SOURCE_FIRST 类型。由项目控制端核验审查者身份、资格证据、目标原生ID及证据索引，然后冻结原始答复及指纹。

## 阶段 B：分歧裁定
独立答复冻结且取得明确授权后，才读取 ExpertComparisonHidden 的本案证据卡。先看4条以内重点证据；额外证据仍保留在完整C1记录中，由专家按需查看。明确支持关系、条件性关系、拒绝等价、未解决或超范围，不强迫在模型双方中二选一。记录修改初始判断的理由和新增证据。填写 POST_INITIAL_COMPARISON 类型并独立冻结。

## 权限与负担
营养测量、物种、安全、临床相关判断由适格专家处理。控制端根据来源和问题匹配资格，不以PI身份自动授权。reviewer_minutes用于估计审核负担；未获得实际审查记录前不虚报完成率或成本。每案保留原始源定位、版本、hash和必要证据。所有模型意见只在第二阶段暴露；文件隔离不代表已经部署强访问控制。当前所有任务状态NOT_ADJUDICATED；任何答复均不自动批准等价、成分迁移、训练、正式参考或MappingRelease。Schema只约束结构，实际提交时还须执行身份、资格、引用、证据和解盲门禁。
