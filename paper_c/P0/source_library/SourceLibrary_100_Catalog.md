## 归档规则

1. 以 `source_id` 统一管理原文、授权、版本、校验和不同格式，不以论文标题作为目录名。
2. 原始 PDF／HTML／XML 保存实际二进制或 UTF-8 原样文件，记录 SHA256、时间、来源 URL、许可；衍生 Markdown 单独保存并注明转换方法。
3. 补充材料如 PDF、XLSX、原始数据集归入同一 `source_id` 下的 `supplements/`，也需独立哈希。
4. 对不允许公开再分发的材料，使用受访问控制的私有资料库；GitHub 只保存清单和许可范围内的文件。
5. 保持资料收集与 PDF 结构化、证据抽取、双语呈现、Workbench UI、专家标注彻底分离。
